# Aseuro Ecommerce Website

Aseuro is a mobile-first, static ecommerce website for beauty, skincare, oral-care, and pet-care products.

## What is included

- Home, shop, product, cart, about, and contact pages
- Product filters and dynamic product-detail pages
- A shopping cart that saves products in the browser
- WhatsApp-based checkout with customer details and order summary
- UPI payment placeholder section
- Responsive design for phones, tablets, and desktops

## Preview the website

Open `index.html` in a web browser. No installation, server, or build step is needed.

## Edit products

Open `js/products.js` to change product names, prices, descriptions, categories, and image filenames.

## Before going live

1. Update the WhatsApp number in `js/main.js`.
2. Replace the UPI ID and QR code placeholder on `cart.html`.
3. Replace the placeholder product images in the `images` folder with your real product photos.
4. Connect a card-payment provider such as Razorpay or Stripe if you want to take card payments directly on the website.

## Technology

Plain HTML, CSS, and vanilla JavaScript. The website can be deployed on GitHub Pages or any static hosting service.
